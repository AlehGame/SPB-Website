# Перенос сайта на хостинг Timeweb

Сайт — набор статических файлов, серверная часть не нужна. Форма заявок работает через Cloudflare Worker, кейсы и отзывы
берутся из Sanity, поэтому на Timeweb переезжают только готовые файлы сайта.

## 1. Подготовка

1. Зарегистрируйте домен (в Timeweb или у другого регистратора) и закажите виртуальный хостинг.
2. В панели Timeweb → «Сайты» добавьте домен. Папка сайта: `public_html` внутри папки домена.
3. Если домен куплен не в Timeweb, в его настройках укажите серверы имён Timeweb (они показаны в панели) или A-запись на IP хостинга.

## 2. Сборка сайта под ваш домен

В корне проекта (PowerShell):

```powershell
npm.cmd ci
.\scripts\build-timeweb.ps1 -Domain coolprint-spb.ru
```

Подставьте свой домен (с `www` или без, как он основной). Скрипт соберёт сайт с правильными canonical, Open Graph,
`robots.txt` и `sitemap.xml`, уберёт файлы, нужные только Cloudflare, и создаст:

- `timeweb\site\` — готовые файлы;
- `timeweb\site.zip` — они же одним архивом.

Папка `timeweb/` не попадает в git.

## 3. Загрузка на хостинг (вручную)

**Через файловый менеджер.** В панели откройте `public_html` домена, удалите заглушку хостера (обычно `index.html`),
загрузите `site.zip` и распакуйте его **прямо в `public_html`**, чтобы `index.html` лежал в корне, а не в подпапке.

**Через FTP.** Данные для входа (сервер, логин, пароль) есть в панели Timeweb. Подключитесь программой FileZilla и скопируйте
содержимое `timeweb\site\` в `public_html`. Файл `.htaccess` (настройки сжатия и кэша) должен попасть в `public_html`
тоже: он скрытый, в FileZilla включите показ скрытых файлов.

## 4. HTTPS

В панели Timeweb выпустите бесплатный сертификат Let's Encrypt для домена и `www`, затем включите переадресацию с `http`
на `https` (переключатель в настройках сайта). Редирект лучше настраивать в панели, а не в `.htaccess`: за прокси
правило по `HTTPS` в `.htaccess` может зациклиться.

## 5. Внешние сервисы (обязательно после появления домена)

Без этого форма и кейсы на новом домене работать не будут.

1. **Форма (Cloudflare Worker).** В `worker/wrangler.toml` добавьте домен в `ALLOWED_ORIGINS` через запятую, например
   `https://alehgame.github.io,http://localhost:5173,https://coolprint-spb.ru,https://www.coolprint-spb.ru`, затем в папке
   `worker/` выполните `npx.cmd wrangler deploy`.
2. **Sanity (кейсы и отзывы).** sanity.io/manage → проект → API → CORS origins: добавьте `https://coolprint-spb.ru` и
   `https://www.coolprint-spb.ru`.
3. Если хотите, чтобы GitHub Pages и локальная сборка тоже использовали новый адрес, поменяйте `VITE_SITE_URL` в `.env`.

## 6. Проверка

- Откройте сайт по `https://ваш-домен/`: кейсы, отзывы, калькулятор, анимации.
- Отправьте тестовую заявку: она должна появиться в Sanity Studio («Заявка с сайта») и прийти в Telegram/на почту, если они подключены.
- Откройте `https://ваш-домен/robots.txt` и `https://ваш-домен/sitemap.xml`: в них должен быть ваш домен.
- Подтвердите сайт в Яндекс Вебмастере и Google Search Console и отправьте `sitemap.xml`.

## Автоматический деплой при каждом пуше (необязательно)

Файл [.github/workflows/deploy-timeweb.yml](.github/workflows/deploy-timeweb.yml) собирает сайт и отправляет его на хостинг
по FTP при каждом пуше в `main`. По умолчанию он выключен. Чтобы включить, в репозитории GitHub
(Settings → Secrets and variables → Actions) задайте:

| Тип | Имя | Значение |
| --- | --- | --- |
| Secret | `FTP_SERVER` | адрес FTP-сервера из панели Timeweb |
| Secret | `FTP_USERNAME` | логин FTP |
| Secret | `FTP_PASSWORD` | пароль FTP |
| Variable | `SITE_URL` | `https://ваш-домен/` (со слэшем в конце) |
| Variable | `TIMEWEB_DIR` | папка сайта на хостинге, например `/ваш-домен/public_html/` (со слэшем в конце) |
| Variable | `TIMEWEB_DEPLOY` | `true` |

Первый деплой лучше сделать вручную (шаг 3), чтобы убедиться, что сайт работает, а потом включать автоматический.
